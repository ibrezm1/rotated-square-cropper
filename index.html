Keyboard Shortcuts & Tips

Arrow Keys Nudge crop box position by 1 pixel
Shift + Arrow Keys Nudge crop box position by 10 pixels
Alt / Option + Arrow Keys Resize width / height by 2 pixels
Ctrl / Cmd + Left / Right Rotate crop box by 1 degree
Ctrl / Cmd + Shift + Left / Right Rotate crop box by 15 degrees
Ctrl + Z / Ctrl + Y Undo / Redo changes

💡 Pro Tip

You can drag the rotation handle (the circle above the top edge) in circular paths for fast rotations, or drag any border edge directly to expand/shrink that side only, even when rotated.
